# 黄金海龟S2：前4单位之后继续每0.5N上移止损——2020—2025年M5与2026年小时K独立对照

**研究日期：2026-10-20。结论：在2019年预热、2020—2025年独立历史阶段，用真实XAUUSD五分钟历史双边报价回放时，保留最多4单位但在进一步顺势上涨/下跌每0.5N时继续移动旧单位的保护性止损，六年累计收益和原版相近，最大回撤显著降低。2024和2025年强趋势中，新方法明显牺牲部分收益；2026年的独立小时K期货实验同方向，但不能混用。**

## 研究设计、价格与执行

- 2019—2025年 `evtradelabs.com/api/simulator/data/XAUUSD/M5/{year}.json.gz`，Dukascopy衍生的**现货黄金历史5分钟bid/ask OHLC**，2019作55日/20日预热，2020—2025连续运行，约496,494根5分钟报价、1,807个纽约17:00划分的日会话；逐年约70,600—71,200根，检查无异常OHLC、重复时间戳及负价差。日内买卖两边按bid/ask方向执行，并加每边0.20美元/盎司滑点、单边5bp的示范费用。**不是COMEX逐合约GC实际交易回放，不包括保证金/融资/换月费用**。
- **海龟S2**：以过去55个已完成交易日的通道突破开仓，20日反向通道退出；用前一交易日的Wilder ATR20=N（不能用当日后续数据）；每走有利的0.5N新增1个单位，最多4；已有单位保护性止损在每次加仓时沿盈利方向上移0.5N，新单位初始反向2N。保护性止损与20日趋势退出并存，任何一个触及对应退出。
- **新方法与原版差异只有一个明确规则**：当已经有4个单位以后，不再实际买入/卖空第5个单位，而是**每再有利运动0.5N，四个已有单位的止损继续移动0.5N**；每次假想跟随移动后的止损若被同一5分钟K的反向报价碰到，用偏保守的当根止损触发近似处理。相同一根5分钟K内的先后报价路径仍然不可知。新止损上移通常可令策略在20日趋势退出之前离场。
- 账户1万美元；基础情景每个单位1N波幅名义风险额度=本金0.5%，固定美元量、不同N对应不同可分割盎司数；只有新建单位时检查名义最多5倍账户权益，**持仓期间不模拟保证金强平**。2025-12-31年末不强制清算，已开仓按当日双边报价市值计入净值；完整交易胜率不包括未平仓交易。
- 技术只使用已经收盘的前日通道和N，不使用未来数据；有一个研究性限制：根据前一根五分钟K线收盘是否已经跨过突破线，避免价格连续处于通道外却重复开仓。
- 此阶段针对2020—2025已知历史行情回放，不是策略研发之前的预注册前瞻检验，也不是经过监管鉴证的真实利润曲线。

## 2020—2025年连续持仓：不同单位上限

|策略|累计收益|全期最大回撤|已完成完整交易|盈利完整交易|年末未平单位|研究中最高毛杠杆|
|---|---:|---:|---:|---:|---:|---:|
|S2原版4单位|**+73.53%**|33.63%|26|8|4|2.71x|
|**S2最多4单位＋继续0.5N移动止损**|**+77.29%**|**12.03%**|44|21|0|2.44x|
|上限8单位持续真实加仓|+139.62%|43.22%|30|5|8|5.51x|
|上限12单位|+117.76%|41.04%|37|12|12|5.32x|
|上限20单位|+174.56%|37.60%|38|13|20|5.42x|

后3组收益因加大杠杆与2025年底显著未实现浮盈而升高，**不能据此说比前2组有更优风险调整后的可交易收益**。连续策略中前2组期末仓位状态不同，虽均按市值统计，但未来继续持有后的结果还会改变。

## 交易成本、仓位稳健性测试（全部采用连续2020—2025年历史数据）

每边$0.20/oz滑点＋每边5bp示范手续费：

|单位风险 / N|原版收益 / 回撤|4单位动态止损收益 / 回撤|
|---|---|---|
|0.25%|+36.77% / 18.77%|**+38.64% / 6.84%**|
|0.50%|+73.53% / 33.63%|**+77.29% / 12.03%**|
|1.00%|+144.65% / 55.12%|**+154.57% / 19.39%**|

当仓位扩大至每N 1%，账面最大毛杠杆曾到5.50x（原版），虽新建订单按5x限制，但因随后的权益变化超过限制；**没有真实保证金强平，不代表实盘风险可以控制**。

单位风险0.50%、每边仍另加0.20美元/oz滑点时：

|单边手续费|原版累计收益/回撤|4单位动态止损累计收益/回撤|
|---|---|---|
|0bp|+77.52% / 31.28%|+83.29% / 11.20%|
|5bp|+73.53% / 33.63%|+77.29% / 12.03%|
|10bp|+69.55% / 36.03%|+71.28% / 12.90%|

成本升高后两个策略都被侵蚀，新的止损法依然没有在上述范围内丢失回撤改善，但收益优势在10bp/边时只剩**1.73个百分点**。这三个成本场景不是独立交易样本。

## 2026年单独校验（非同源数据，不能与上面合并计算）

由于同一XAUUSD五分钟接口查询2026年出现**401未授权**，只能用先前2026年 **Yahoo `GC=F`连续黄金期货1小时K线，2025年预热，2026年1月空仓、截至10月16日** 对照。期货品种、数据切割、频率、bid/ask成本模型与上面不同，只可看策略方向。

|模拟单位风险|2026原版4单位收益 / 最大回撤|2026只持4单位，继续0.5N追踪止损收益 / 最大回撤|
|---|---|---|
|每N 0.25%|-2.05% / 11.33%|+4.30% / 5.58%|
|每N 0.50%|-4.11% / 20.70%|+8.60% / 10.19%|
|每N 1.00%|-8.21% / 35.29%|+17.20% / 17.37%|

在2026年单一年份模拟里也出现改善；但最主要利润来自**2026年1月12日多单在1月29日提前止损锁盈**，因此不能说这已通过真正独立数据或实盘验证。1h内部OHLC成交先后不可见。

## 重点风险与研究建议

1. **结果不同年份差异很大**。2024和2025是典型牺牲大趋势收益以改善回撤；任何未来年度若金价单边连续涨，这一成本可能复现。不能单靠累计收益+77.29%和最大回撤12.03%做决定。
2. M5现货bid/ask源公开可获得，历史时点资料但并非交易所原始tick和真有可成交深度；五分钟OHLC无法确定盘内止损、加仓、跳空和滑点先后，至少2次动态止损情景中同根加仓/止损存在无法排序的触及。本研究以同根触及则保护性止损优先，不构成已验证的真实成交报告。
3. 新版更频繁出场重新入场（44 vs 26笔已完成交易），增加成本和实时委托执行复杂性。
4. 原版完整海龟还含账户减仓（如10%权益下跌相应缩小单位）、真实期货整数张数、跨品种组合风险等；单市场XAUUSD只是S2规则代理，不是完整原版资金组合。
5. 原始思想为2026年回测后提出，再用2020—2025年检验。因此这是**历史异期验证**，并非未接触模型开发信息的纯前瞻样本外统计验证。后续必须固定规则再用未来月份检查或拿到同口径逐合约2026 M5再测。
