# 黄金S2海龟：2020—2025年真实4小时55/20与不限加仓对照（5分钟双边报价执行代理）

研究日：2026-10-20。源脚本 `gold-turtle-2020-2025-H4-unlimited-vs-4unit-trail.js`。这是研究分支的独立历史模拟，不更改任何生产黄金策略。

## 先说明本研究真正测试的周期

所有技术参数均以**4小时K线**计，而非日K或1h：过去55根**完整4h**最高最低价突破开多/空，过去20根完整4h反向退出；N=Wilder SMA1(TR,20) 用前一已完成4h的N，入场后每有利运动0.5N加一单位，新仓初始反向2N保护性止损、旧仓每次真实加仓反向止损顺势抬高0.5N。另有20根4小时区间趋势退出，先触发者优先。

预先固定三组：
- A `H4_original_4`：移植到4h的S2，最多4单位，后续**不再加仓或因未加仓自动移动2N止损**，只按20K通道或既有2N止损退出。
- B `H4_unlimited_adds`：不使用4、8、12、20单位人为上限；每跨有利0.5N继续实加仓、旧单位每加仓向有利方向调整0.5N止损；**仍必须满足新增敞口名义5倍账户净值限制**。内部500单位仅防无限循环，实际未达到。真实最多同时持有15单位、单笔行情实际累计最多18个追加单位序列（该笔最高记录18个总单位）。
- C `H4_virtual_4`：最多4个真实单位，之后每有利移动0.5N，继续调整旧单位保护性止损0.5N，不添加第5单位；趋势通道照旧有效。用户此前提出的“动态上移动止损”。

## 数据、风险和成本

- 2019预热，2020-01-01—2025-12-31连续交易，2019—2025共**496,494根**XAUUSD现货5分钟历史bid/ask OHLC，源为EV TradeLabs/Dukascopy衍生报价。按纽约17:00交易日划分4小时区间，共**10,820根4h组**，其中10,776组包含36—48根5分钟K、44组为更短交易时段。2020、2021、2022、2023、2024、2025各年没有人为挑选具体交易。
- 每组按5分钟报价路径推演：多头买入用ask，平仓用bid；空头开仓用bid，平仓用ask，附加每边$0.20/盎司滑点，以及按名义成交额每边**5bp手续费**（总往返约10bp），均为假设而非用户富途或交易所历史账单。日K/4h指标在当前时间之前完全完成才参与决策；同根5min K触及开仓+止损，按保守止损触发近似，仍未能恢复根内真实撮合顺序。
- 假设初始账户$10,000，每新增单位盎司数=$10,000×**0.5%/N**，**资金规模固定初始本金**，未根据每年利润复利扩大每个单位的盎司数；标记账户权益仍随着持仓逐笔变化。单位成交按可分割盎司模拟，绝非100盎司GC期货整数张数。新增订单检查总名义敞口不超过当时权益**5倍**；持仓之后权益下跌可能导致观测杠杆超过5倍，**未模拟经纪商维持保证金、强平、融资和掉期**。
- `blocked` 数值是每根5分钟K持续尝试却因杠杆额度不足的**重复判定次数**，不是独立真实订单数，不能按次数解读。
- **重大可执行性风险**：此处用现货XAUUSD回放以获得5分钟bid/ask，并非GC期货逐合约。因而结果**不能与2026年Yahoo连续GC=F小时K回测的数字直接拼接或同视为真实可交易账户业绩**。

## 敏感性：结果对成本特别敏感

2020—2025连续、初始每单位0.5%/N、新增名义敞口上限5倍、另有每边$0.20/盎司额外滑点：

|单边成交手续费|A 原版收益/回撤|B 不限加仓收益/回撤|C 动态止损收益/回撤|
|---|---|---|---|
|0bp|+101.70% / 57.42%|-5.61% / 67.48%|+64.67% / 45.46%|
|**5bp（主情景）**|**+4.66% / 72.47%**|-13.69% / 75.34%|-6.82% / 68.39%|
|10bp|-66.35% / 90.57%|-70.34% / 90.88%|-49.02% / 83.59%|

**不能说0bp为真实免费交易**：报价内存在bid/ask点差，另加$0.20/oz每边滑点。但成本从0→5→10bp造成截然不同的策略收益，证实4h短周期对手续费、交易频率很敏感。

## 完全没有杠杆容量限制的压力测试：不具有实际可执行性

如果**取消订单新建5倍名义杠杆检查**，仍允许无限加仓，在同一套2020—2025年报价上：
- B无限加仓：六年-101.34%，出现账户净值低于零、最大模拟回撤超过100%（100.49%），最高模型毛杠杆27,209倍，**这是缺少保证金强平的计算路径失效，不应当作真实可执行仓位或预测收益**。实盘通常会在此之前因保证金不足、风控或强平终止。
- A原版4单位：+58.11%、最大回撤70.63%、模型最高14.62x杠杆。
- C移动止损：-44.50%、最大回撤85.37%、模型最高32.37x杠杆。

**因此必须同时保留资金/保证金限制，不允许把“不限加仓”理解为真正无限资金和无限杠杆。**

## 可信度与下一阶段

- 使用了过去已收盘4h价及N，技术指标不含未来函数；但五分钟OHLC无法确认同一根5min内先后成交。A/B/C分别记录到少量“同根加仓与保护止损”触及，均按保守退出近似处理。
- 源是现货XAUUSD双边报价代理而非用户富途的XAUUSD实盘可成交深度，也不是GC期货逐合约成交和换月，缺少不同经纪商点差、佣金、保证金、隔夜融资、滑点压力场景及整数合约限制。和2026年GC=F连续期货小时K线的+15.66%（C组）**并非同源可比**，不能合并为“2020—2026完整样本”。
- 此次研究基于**已知2026年曾出现4h动态止损优于原版**之后提出的组合，因此2020—2025虽是不同年份，不能声称从未看过的严格前瞻样本外检验；不应在2020—2025年继续挑选表现最好看的参数后宣布“神奇交易系统”。
- 重点实证判断：在**这次成本模型和保证金约束下**，2020—2025真正4h 55/20频率较高、完整交易平均只有低约20%胜率，三组全期最大回撤68%—75%，不满足较稳健风险管理的要求。扩大真实仓位并未改善收益；仅提高止损移动频率提高了交易胜率且降低一定回撤，但依旧没改善总收益。
- 下一阶段：比起再增加真实加仓单位数，更合理的改进是用数据核对2026的同源XAUUSD五分钟价，和2020—2025统一实际成本及成交；然后事先冻结风险条件，拿未来独立时段验证。
