# 2026年黄金海龟S2 + 基本面过滤/仓位加减：相同小时线回测（2026-10-19）

## 核心结论

**本次2026年样本中，没有发现宏观基本面叠加能稳定改善S2金字塔海龟的收益。** 在2026-01-01从空仓$10,000起算、2026-10-16结束的同基准回测中，纯S2收益-8.21%；跨类别宏观风险否决版-17.27%，不利减半仓版-12.48%，宏观确认才加仓版-17.68%，组合版-17.21%。一些变体降低了回撤，但错过了关键盈利趋势，不能因回撤降低就宣称综合效果更好。

## 必须明确：不是2026年5分钟原版合约成交

- 价格：Yahoo `GC=F` 2025-01至2026-10-16的**有效1小时OHLC，10,295根**（2026年约4,537根），非2026五分钟报价，非逐合约COMEX真实委托。
- 原始Yahoo时间戳中还有2,747个OHLC均为空的占位时间点，其中2,198个落在主要周末闭市、448个在每天17时换盘停顿，仍有101个平日缺失小时可能属于假日和不规则时段；有效bar之前剔除空值，**不能宣称小时数据无缺漏**。
- 以美国纽约17:00换交易日，2026年1月至10月16日有204个含有效K线的交易时段。
- 2025年价格为2026年55日、20日、N指标预热；另外以2025年4月空仓起步逐根持有到2026年10月，专门衡量2025年末已有持仓在2026年的表现；**不是从2020年就一直连续持有的原海龟组合**。
- 四个基本面数据系列：FRED `DFII10` 10年TIPS实际利率，Yahoo `DX-Y.NYB` 美元指数，财政部DTS `TGA`，SPDR GLD实物持仓吨数变化；CFTC Managed Money仅附带留作诊断，没有加进四项投票。
- 时间约束：FRED利率/DTS/GLD按照研究版本保守延迟3日、DXY延迟2日才可使用，7个自然日变化在每个交易决策时刻已知才计票；并未拿到官方逐期“初次发布vintage”、分钟级释放时点，不能认证绝对无数据修订偏差。

## 冻结的五种策略

所有版本共同技术规则：**海龟S2**，突破此前已收完的55个交易日最高/最低价建仓；使用前日20日Wilder N；初始每单位2N保护止损；向有利方向每0.5N加仓；一段独立趋势累计最多4单位；持仓中触发前20个已结束交易日的反向区间时退出；按独立单位的2N跟进止损先后执行。全都从同样$10,000模拟资金出发，按1N约等于原始账户1%计算可分割盎司仓位，名义敞口不超过约5倍；往返合计10bp + 每边$0.20/盎司附加滑点。OHLC同根内价格顺序不明时采用不利假设，其他成交误差仍存在。

指标方向对**做多**：
- 近7自然日10年实际利率下降：支持；上升：反对。
- 近7自然日DXY下降：支持；上升：反对。
- 近7自然日TGA余额下降：假设为利多流动性（粗糙代理，现实并非稳定因果）；上涨：反对。
- 近7自然日GLD持仓吨数增加：支持；下降：反对。
- 做空方向相反。**美元与实际利率可能高度相关，TGA与GLD亦不等于真实美元资金流净额。**

版本：
- **A 纯海龟**：不检查基本面。
- **B 入场否决**：利率或美元至少一项反对，且TGA或GLD至少一项也反对时，禁止该小时新开仓。
- **C 缩风险**：触发跨类别双反对时，该次单位仓位减半，仍可按基础技术加仓。
- **D 加仓确认**：首次突破照开，但只有利率/美元中至少一项支持、TGA/GLD中至少一项支持时，才能按0.5N加下一单位；整个趋势累计最多4单位。
- **E 组合**：C的风险减半与D的加仓确认同时执行。
- 这些门槛是研究性固定设定，而非基于2026年的收益拟合。

这个口径中，五版2026年收益非常接近，**基本面并未带来能够辨认出的稳健额外贡献**。2025年9月建立的多头，直到2026年3月才退出，是大部分2026年正收益的原因。2026年新进入的5笔交易仍多数亏损。注意各组进入2026年的初始权益不相同，2026收益比例比较与完整2025—2026累计收益不是同一问题。

## 策略评价

- **单纯做基本面方向否决，可能错过海龟最重要的趋势盈利。** 2026年空仓测试明确出现这种情况。
- 风险减半能够降低峰值回撤，却不能保证风险调整后表现更优；这次在纯2026空仓口径下最终收益更差。
- 限制加仓不会自动防止亏损；改变加入第二/第三单位的时间后可能改变止损的轨迹，使损益比恶化。
- 2026年的独立交易仅5—6笔，统计功效严重不足。基本面指标相互关联且发布时间仅做保守近似，因此不能证明“加入宏观从长期看无用”，也不能依据2026一段数据搜索新阈值。
- 当前研究不是完整黄金V2.2的财政预期D+1/3/5与收益率成因拆解，没有把期限溢价、准备金、SOFR-IORB、油价/地缘情景或CFTC净多动态预测真正融合进信号。这次专门测试**四个可追溯基础数据的最小宏观叠加**。
- 更重要的是，真正的海龟按合约张数、跨期换月和每周更新单位执行；本回测用可分割盎司、连续期货1小时代理和账户5倍名义限制，不能宣传为100%原始海龟实际可交易业绩。
- 2026年7—10月尚无足够新增完整S2趋势样本，出现“几乎所有版本无新交易”不代表其间市场没有波动。

## 决策

**暂时保留不含基本面的一致性S2技术基准；基本面只做观察和情景判断，不根据本轮结果启用任何自动开仓、否决或加仓限制。** 若继续检验，应使用更完整的发布时点数据、逐合约真实成交，并保持冻结规则评估更多年份或新前向信号，而不是仅优化2026年已知样本的门槛。
