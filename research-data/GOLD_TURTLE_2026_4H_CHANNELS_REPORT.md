# 2026年黄金海龟：4小时55/20突破、动态追踪止损与日线对照

研究日期：2026年10月20日。独立研究分支，不修改生产监控。

## 用户问题的两种理解

1. **真正改成4小时海龟**：55根**已结束的4小时K线**突破；20根4小时K线反向退出；20根4小时Wilder ATR作为N。新方法：最多4单位，但后续价格每顺势0.5N继续移动已持有单位的2N保护止损，而不增加新仓。
2. **仅以4小时图操作原55交易日海龟**：保持前55个已结束交易日入场、20个交易日退出、20日ATR，但用小时K更细地捕获入场和退出。为尽量区分时间周期，另计算330根/120根4小时K近似55/20交易日跨度的敏感性版本。**330/120不与逐日55/20严格等效**，因跨交易所日程、休市及部分交易时段影响。

## 价格来源与统一执行

- 历史 `Yahoo GC=F` 连续黄金期货 **1小时OHLC**：2025-01-02—2026-10-16共10,295根有效小时K、2,747条无OHLC时间戳（多为非交易时段）；2015没有用。2025年预热，**2026-01-01空仓**，截至2026-10-16完成交易日。
- 以美国纽约时间17:00为日会话开始，每4小时聚合小时K：得到2,702根历史4小时K，其中4小时组有完整4小时的2,233根，含3个小时的444根，其他25根更短；部分短K与交易时段安排有关。**与券商富途的4小时切割方式可能不同**。
- ATR(20)用前一根已经**完成**的4小时K及以前历史；通道55/20排除当前4小时K，避免未来函数。每小时评估价格是否触发，交易不是假定在4小时收盘成交。
- $10,000模拟初始账户、基础每单位 (q=$10000×0.5\% /N) 可拆分盎司数，另以0.25%及1%/N作仓位敏感性。每边5bp示范手续费＋每边$0.20/oz滑点；0/5/10bp对照。开新单位时名义杠杆不超过5倍净值的粗略限制，持仓后无保证金强平/融资成本。
- 加仓每0.5N一次，单位初始2N止损，旧单位每次真实加仓上调/下调0.5N，20根对应周期的反向通道退出保持有效；最多4个真实单位的“virtual”版本，达到4单位以后仍每0.5N有利运动继续上移旧单位保护止损，不再买新单位。单小时同时触发加仓和止损时，使用偏保守的小时止损触发近似，**真实先后不可确认**。

## 4小时“55根”和日线“55天”并不相同

|通道时间框架|原版最多4单位收益 / 最大回撤|4单位后继续追踪止损收益 / 最大回撤|完整交易原版→动态|
|---|---|---|---|
|**55根4h入场／20根4h退出**|-0.45% / 34.18%|**+15.66% / 15.38%**|32→38|
|**330根4h入场／120根4h退出**（近似日线时长）|-19.16% / 42.85%|**+12.70% / 9.36%**|8→10|
|**55个已结束交易日入场／20交易日退出**|-4.11% / 20.70%|**+8.60% / 10.19%**|6→7|

因此4小时55/20的交易频率明显高于日线55/20，但“周期更短”不能等同“可盈利性更强”。日线基准与上一轮在0.5%/N下的 -4.11%/+8.60% 完全一致，说明运行规则在该设置下被成功复现。

## 主样本具体交易风险

- 55根4h新方法已完成38个行情，其中11个盈利；盈利率**28.9%**。原版32笔、5笔盈利，15.6%。
- 动态止损版本一笔较大盈利：2026-01-27多头，2026-01-29退出，约+$1,310.77；2026-03-15至03-19空单约+$1,213.01。**不是所有盈利都来自同一笔，但利润分布仍集中**。
- 模型录入历史缺失的1小时K 2,747条，主要为非交易时段；在2026年2月2日18:00Z前后，连续小时价格发生约-7.70%跳变，可能是市场实际跳空或连续期货换月等因素造成，**必须核对真实合约成交和时区**。另有3月1日、6月14日两个超过2%的缺口。不能把连续报价的价格跳变直接视为真实可成交的止损。
- 4h K内OHLC无法还原真正走势顺序；用小时K执行也仍存在小时内先后歧义，虚拟止损尤其敏感。主组检测到一次同小时入场与止损触及、动态止损还有4次同小时追加与止损的不确定情况，采用不利止损假设，但未模拟精确真实成交。
- 这不是富途XAUUSD原始报价；富途的实际K线切割、点差、交易合约与Yahoo GC=F价格源不同。不是交易所原始合约换月/交易所成交日志。无法确保按模拟水平成交。
- 原始海龟还有跨商品相关性单位上限、账户名义风险减仓、真实整数合约等；本实验专测黄金S2单市场，并不包含完整原版海龟资金管理。

## 提议

作为下一阶段候选，固定**4小时55/20 + 最多4个真实单位 + 之后每0.5N虚拟上移保护止损**的明确定义，先用2019—2025年可取得的现货黄金5分钟双边价重新合成4小时信号并做历史异期核验，再对2026年2月黄金大缺口的真实期货合约价格及同小时成交路径检查后考虑模拟盘。不能在2026样本反复寻找更漂亮的ATR/通道周期，然后称之为已验证的独立优势。
