# 2026年黄金S2海龟：真正使用1小时55/20突破、ATR(20)及动态止损回测

**研究时间**：2026-10-20；回测窗口2026-01-01至10-16已经结束的交易时段，2025年作为技术指标历史预热。研究分支 `research/v22-data-audit-20261016`，不修改生产监控。

## 严格定义

- 主研究：**55根已完成1小时K线突破建仓、20根已完成1小时K线反向退出、前一已完成1小时K线ATR(20) Wilder N**。这是实质性缩短市场时长：55个交易小时大约2—3个交易日，而不是55天。
- 原版对照S2单品种：每向有利的0.5N追加一个单位，最多4个；新单位止损2N，旧单位在追加时沿有利方向移动止损0.5N；趋势退出使用20根1小时K线反向通道。动态版是达到4个真实单位以后，价格每继续顺势0.5N只移动旧单位的2N保护止损，不再新建第5单位。另试实际总单位上限8/12/20。**此处“原版”指原S2机制移植到1h，不是原文使用55交易日的真实历史策略。**
- 报价：`Yahoo GC=F` 近月黄金连续期货1小时OHLC；2025-01-02至2026-10-16有效10,295根小时K；2,747根原接口时间戳缺失OHLC，已排除（大多在非交易时段）。**没有真实COMEX逐合约的换月执行**；2026-02-02T18:00Z附近相邻小时开盘对前收盘约-7.70%跳变，可能涉及连续期货换月，须逐合约核查。
- 同一执行模拟器回测：1小时当前OHLC检测触价，不使用未来小时报价；指标严格只用当前小时前已完结的K线。账户$10,000；每新单位名义q=$10,000×0.5%/N，可以买卖分数盎司，不对应真实GC整数期货；新开仓名义总敞口上限为当时账户净值5倍；无维持保证金检查/利息和强平模拟。每侧5基点交易费用加每侧0.20美元/盎司额外滑点。相同条件用2026年4小时和55交易日日线基准复现。
- 强限制：**小时OHLC不知道该小时先达到入场的高点，还是先出现保护止损的低点**，模型采用新单/追加单位同根低高价也触及时立即保守止损的“stop-first”路径模型，可能大幅低估现实收益；反过来如果一律假设不利低点先于入场、因而不在当前小时内执行新单保护止损，也可能大幅高估。必须阅读成交路径敏感性。

## 最重要的成交路径压力测试：时间精度不够导致方向翻转

在**完全相同1h OHLC**、同样N风险0.50%、手续费单边5bp情形下：

|同小时出现入场/加仓与保护止损|原版收益/回撤|4单位后动态止损收益/回撤|
|---|---|---|
|悲观路径：同一根小时K若同时触发则按“止损已经发生”|-56.81% / 73.80%|-77.00% / 79.94%|
|乐观路径：假设当前小时不利高低价发生在建立/上调止损**之前**，暂不执行该新止损|+5.63% / 43.50%|-19.37% / 49.62%|

这是**两个模型构造的极端执行路径假设**，绝不等同统计置信区间或者真实交易上下界，也不能说原版会真实盈利+5.63%。原版即使在乐观假设下仍有43.50%回撤，动态跟踪即使在乐观假设下仍显示亏损。两组结果巨大分歧表明：**目前1小时OHLC不适合验证1小时海龟的真实盈亏**。主模型标记过26次原版新入场/止损同小时触及，20次原版加仓/止损同小时触及；动态版标记27次入场、26次加仓/止损同小时触及。乐观假设下仓位路径改变，歧义计数也改变，不可直接相加比较。

附加测试禁止价格已经突破历史通道后重复入场（上一已收盘小时报价确认的fresh crossing）在该滚动最高/最低计算中不改变结果，因为前1h收盘本身处于此前55小时高低范围内，这个测试不能解决同小时执行歧义。

## 初步结论与下一步

1. 1小时55/20海龟远较4小时版本高频，在基准悲观假设下明显亏损，而且4单位后继续动态收紧保护止损表现更差。**不能把“2026年每小时亏损-77%”当作可审计真实成交数据**。
2. 与更缓慢的4小时 / 日线相比，小时N缩短使止损太接近噪声；此外交易费和反复重入场进一步侵蚀收益；这一因果解释尚须逐笔时间线和精细数据交叉验证。
3. 强烈需要2026年GC逐合约5分钟或1分钟成交，确认入场/止损先后、换月影响，统一真实每张合约费用与保证金；而此前EV XAUUSD现货M5年份接口的2026年返回401未授权。
4. 优先维持4小时+4单位后动态止损作为**候选研究策略**，而非立即根据单年漂亮数字实盘；下一阶段应拿2020—2025年M5双边现货价构造真实4h信号检验。
5. 极短周期研究可另定55小时 /20小时但需用5分钟价回测执行，再比较15/30/60分钟止损；**任何新参数必须预先固定**，防止因2026年已知亏损而挑回测最好看的组合。
